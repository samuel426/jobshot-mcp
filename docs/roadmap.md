## 현재 작업: 1단계의 첫 PR

개인 자료 목록 조회와 공고 이미지 한 장의 안전한 저장부터 구현한다.
런타임·MCP SDK와 파일 입력 경로를 구현했다. Codex/Claude UI의 첨부 전달 경로 확인은 남아 있다.
긴 이미지 분할은 같은 단계의 별도 PR로 나눌 수 있다. 달력·서류·Google 연동을 앞당겨 넣지 않는다.

다음 PR은 긴 이미지 분할·좌표 기록과 클라이언트 입력 흐름 확인을 다룬다.

## 검증해야 할 설계 항목

- 클라이언트에 붙여넣은 이미지의 실제 파일 접근 방식과 스킬 설치 방식.
- 날짜만 있는 공고의 표시와 사용자 확인 동선.
- Google 로컬 OAuth 설정·배포 요건과 실제 필요한 권한.
- macOS 파일 입력 및 한글 경로 동작. 확인 전 지원 완료라고 쓰지 않는다.
- 오픈소스 라이선스 선택과 의존성 라이선스 검토: 첫 배포 전 확정.
- 2단계 후 친구에게 달력을 보여주고 문제 해결 여부를 먼저 확인.
