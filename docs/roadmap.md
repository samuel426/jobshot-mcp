사용자가 첨부한 가상 공고로 Windows 실제 클립보드와 Codex 첨부 파일 전달을 확인했다.
프로젝트 신뢰 등록과 설정 적용은 완료됐고, Codex App Server 임시 세션에서 도구 발견·호출을 확인했다.
현재 앱 대화의 입력 도구 직접 호출도 확인했다. 2026-11-05 사용자 결정으로 첫 미리보기는 Windows·Codex용이며 Claude Code·macOS 실사용은 지원 확대 전 검증으로 남긴다.
로컬 달력은 등록한 공고만 표시하며 날짜 미정·상시 목록, 원문 링크, 오늘 강조·월 이동과 날짜 갱신을 제공한다.
DOM 테스트와 실제 브라우저 확인은 구분한다. 2026-10-23 사용자 캡처에 이어 2026-11-04 Chrome에서 월 이동·원문 링크·CSP 적용과 좁은 화면을 직접 확인했다. [재현 절차](dashboard-browser-check.md)를 따른다. 파일 직접 열기·휴대전화 실기기·친구 피드백은 이 결과에 포함하지 않는다.
직무 적합도 저장에 이어 `application_save`로 자소서·이력서 초안과 평가를 항상 함께 별도 버전으로 저장한다. 자소서는 기존 v0.1 배점·자료 버전·정확한 인용·미확인 점수 유보와 항목별 감점 이유를 적용한다. 이력서는 강점·부족한 근거·개선안을 평가하고 숫자 점수는 유보한다. 공고 상태와 원본을 유지하고 JSON·Markdown 완성 후 버전 폴더를 공개한다.
세부 사용법은 [직무 적합도 저장](job-fit.md)과 [지원서류 저장](applications.md)을 따른다. 2026-11-04 현재 대화에서 가상 자료로 분석·자소서·이력서 저장, 수정본·평가 유보·실패 안내와 이전 버전 보존을 확인했다. 사용자가 가상 예시의 평가 설명 이해와 방식 유지를 확인했으며 실제 플랫폼 글자 수 대조는 남아 있다.

Google 첫 버전은 기존 캘린더 선택 대신 JobShot 전용 보조 캘린더와 `calendar.app.created` 권한을 사용한다. `calendar_preview`와 `calendar_sync`로 로컬 등록과 독립적으로 전송한다. Windows DPAPI로 인증 정보를 보호하며 외부 변경·삭제·부분 실패를 구분한다. 실제 계정 API 검증에 이어 2026-11-04 현재 대화의 전송·화면·제품 연결 해제·토큰 철회·로컬 대체·재연결·정리를 확인했다. 이번 삭제 후 재전송은 자동 승인 검토가 거부했으므로 이전 API/자동 테스트 결과와 구분한다. [Google 연결 안내](google-calendar.md)와 [최신 기록](work-log/2026-11-04.md)을 따른다.

실사용 범위와 남은 항목은 [클라이언트 실사용 체크](client-validation.md)에 기록한다.
Google 연결·전송 실패나 충돌이 나면 같은 공고를 로컬 웹 달력에 자동 등록한다. Google 성공과 로컬 등록/화면 생성 결과를 구분한다. 입력 오류·동시 변경·로컬 기록 불명확 시 자동 등록을 중단한다. [2026-11-01 작업 기록](work-log/2026-11-01.md)을 따른다.
이전 원본 전용 기록의 분할본 추가는 아직 지원하지 않는다. 원본을 지우고 다시 입력하도록 안내하지 않는다.
