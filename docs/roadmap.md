## 현재 작업: 3단계 지원서류 버전·문항별 평가

새 공고 입력 시 원본을 보존하고 긴 이미지를 겹침·좌표가 있는 PNG 조각으로 저장한다.
Windows 캡처 CLI → inbox 파일 → MCP 원본·분할본 저장 경로를 제공한다.
사용자가 첨부한 가상 공고로 Windows 실제 클립보드와 Codex 첨부 파일 전달을 확인했다.
프로젝트 신뢰 등록과 설정 적용은 완료됐고, Codex App Server 임시 세션에서 도구 발견·호출을 확인했다.
현재 앱 대화의 입력 도구 직접 호출도 확인했다. Claude Code·macOS 실사용은 사용자 승인에 따라 5단계 배포 전 검증으로 남긴다.
로컬 달력은 등록한 공고만 표시하며 날짜 미정·상시 목록, 원문 링크, 오늘 강조·월 이동과 날짜 갱신을 제공한다.
DOM 테스트와 실제 브라우저 확인은 구분한다. 2026-10-23 사용자 캡처로 데스크톱 화면을 확인했고 친구 피드백은 남아 있다.
직무 적합도 저장에 이어 `application_save`로 자소서·이력서 초안을 별도 버전으로 저장한다. 자소서 문항별 평가는 요청 시 포함하며 기존 v0.1 배점·자료 버전·정확한 인용·미확인 점수 유보를 적용한다. 이력서에는 자소서 배점을 적용하지 않는다. 공고 상태와 원본을 유지하고 JSON·Markdown 완성 후 버전 폴더를 공개한다. Google 연동은 4단계다.
세부 사용법은 [직무 적합도 저장](job-fit.md)과 [지원서류 저장](applications.md)을 따른다. 2026-10-25 작업은 기능·자동 검증 범위이며 현재 앱의 새 서류 도구 직접 호출은 연결 갱신 후 확인한다.

실사용 범위와 남은 항목은 [클라이언트 실사용 체크](client-validation.md)에 기록한다.
이전 원본 전용 기록의 분할본 추가는 아직 지원하지 않는다. 원본을 지우고 다시 입력하도록 안내하지 않는다.

## 검증해야 할 설계 항목

- 클라이언트에 붙여넣은 이미지의 실제 파일 접근 방식과 스킬 설치 방식.
- 날짜만 있는 공고의 표시와 사용자 확인 동선.
- Google 로컬 OAuth 설정·배포 요건과 실제 필요한 권한.
- macOS 파일 입력 및 한글 경로 동작. 확인 전 지원 완료라고 쓰지 않는다.
- 오픈소스 라이선스 선택과 의존성 라이선스 검토: 첫 배포 전 확정.
- 2단계 후 친구에게 달력을 보여주고 문제 해결 여부를 먼저 확인.
