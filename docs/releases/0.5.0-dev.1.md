# 0.5.0-dev.1 개발 버전

2026-11-04. 공개 배포판이 아닌 UI 개편 개발 버전이다.

## 변경

- 큰 소개 배너·장식 카드·둥근 강조 요소를 줄이고 제목, 일정 수, 월간 달력 순서로 정리했다. 흰색·회색 바탕과 오늘 날짜의 한 가지 강조색을 사용한다.
- 로컬 등록과 Google 전송의 차이는 하단에 유지하고 자세한 설명은 ‘일정 관리 안내’로 접었다.
- 좁은 화면에서 처음 열거나 ‘오늘’을 누르면 오늘 날짜가 가로 스크롤 영역 안에 보인다. 월 이동·키보드 이동·원문 링크·날짜 미정/상시 목록을 유지한다.
- package.json, 잠금 파일과 MCP 서버의 버전 표기를 0.5.0-dev.1로 맞췄다. 데이터 형식·Google 권한·의존성은 바뀌지 않았다.

## 적용

변경이 병합된 소스를 받은 뒤 `npm ci`와 `npm run build`를 실행하고 MCP 클라이언트를 재시작한다. 대화에서 ‘로컬 달력을 다시 만들어줘’라고 요청한 뒤 기존 HTML 페이지를 새로고침한다. 이미 생성된 HTML은 소스 업데이트만으로 자동 변경되지 않는다.

가상 자료로 화면만 확인하려면 [브라우저 검증 절차](../dashboard-browser-check.md)를 따른다. 개인 자료나 Google 연결은 필요하지 않다.

## 확인 범위와 다음 단계

Windows Chrome의 320·390·768·1440 CSS 픽셀 화면, 월/연도 이동, 오늘 복귀, 원문 새 탭, 빈 달력, 접힌 안내와 CSP 6개 차단을 확인했다. 루프백 HTTP에서 실행했으며 파일 직접 열기·휴대전화 실기기 검증과 구분한다.

공개 릴리스·패키지 게시·서버 배포는 하지 않았다. 다음은 [배포 준비 #6](https://github.com/samuel426/jobshot-mcp/issues/6)의 새 환경 설치, 지원 범위·라이선스·OAuth 배포 요건 정리다. 상세 검증은 [작업 기록](../work-log/2026-11-04.md)을 따른다.
