# 2026-11-08 소스 설치형 의존성 고지

## 범위

- 사용자 요청에 따라 남은 배포 준비 중 의존성 고지 정리 한 항목을 진행했다. 이슈 #29를 만들고 최신 main `0d1f87c`에서 `codex/source-distribution-notices` 브랜치를 생성했다.
- 기존 결정인 Windows·Codex 소스 설치 방식과 MIT를 유지한다. 제품 기능·의존성 버전·Google 설정·Vercel 배포는 변경하지 않았다.

## 확인과 결과

- Git 추적 파일에 node_modules·dist·vendor와 실행 파일·네이티브 모듈·배포 압축 파일이 없음을 확인했다. 정적 웹 예시의 외부 패키지·CDN·폰트·이미지 의존성도 없었다.
- 직접 의존성 7개의 설치 버전·고지 위치를 대조했다. 잠금 파일상 런타임 중 이 Windows x64 환경에 설치된 11개는 모두 버전이 일치하고 고지 파일이 있었다. 모든 OS의 전체 설치 개수를 뜻하지 않는다.
- MCP server/core/client 2.3.1의 LICENSE는 패키지의 Apache-2.0 선언 외에 MIT에서의 전환과 문서 CC-BY-4.0 안내를 포함했다. 상위 공식 LICENSE와 대조하고 기존 선언 목록을 덮어쓰지 않는 별도 설명을 추가했다.
- Windows sharp 0.35.5 README의 29개 라이브러리와 versions.json의 28개 버전을 연결했다. libnsgif 버전은 파일에 없어 미확인으로 표시했다. 고지 원문의 식별용 해시와 업데이트 절차를 남겼다.
- [제3자 의존성 안내](../third-party-notices.md)를 README·배포 준비·로드맵·선언 목록에 연결했다. 선언 목록 생성기도 링크를 보존한다.
- 현재 소스 설치형 고지 정리는 완료했다. 바이너리 묶음 배포 검토를 완료한 것으로 표시하지 않는다. Google 공개 방식·독립 사용자 첫 사용·휴대전화·친구 피드백·릴리스는 별도 미완료다.
