# 2026-10-18 — MCP 설정 제외 원인 확인과 연결 안내

## 범위

[이슈 #2](https://github.com/samuel426/jobshot-mcp/issues/2)의 클라이언트 연결 재확인을 진행했다.
`codex/mcp-connection-troubleshooting` 브랜치에서 연결 장애 원인과 복구 순서를 문서화한다.
제품 기능과 설정은 변경하지 않았으며 달력 단계는 시작하지 않았다.

## 확인한 결과

- 현재 대화에 JobShot 도구가 노출되지 않음을 다시 확인했다.
- 앱에 포함된 CLI 0.163.0-alpha.10.2에서 읽기 전용 `config/read`를 호출했다. 프로젝트 계층에 `jobshot_test`가 있으나 신뢰 등록이 필요하다는 `disabledReason` 때문에 제외됐다.
- 현재 프로젝트 `.codex/`에는 테스트 작업 폴더를 가리키는 MCP 설정 파일만 있었다.
- 프로젝트 신뢰 등록은 설정·훅·실행 규칙의 신뢰 범위에 영향을 주므로 사용자에게 선택을 요청했다. 답변 전에 설정을 변경하지 않았다.
- PATH에서 Claude Code 실행 파일을 찾지 못했다. 설치 여부 전체를 확인한 것은 아니며 클라이언트 검증 완료로 기록하지 않는다.
- 개인 자료·첨부 이미지·인증 정보는 읽거나 변경하지 않았다. 공개 문서에는 개인 경로나 진단 로그 원문을 넣지 않았다.

[실사용 체크](../client-validation.md)와 [로드맵](../roadmap.md)에 설정 제외 원인과 미완료 범위를 반영했다.
신뢰 설정 적용 후 Codex 앱 직접 호출, Claude Code, macOS 검증은 남아 있다. 이슈 #2는 열린 상태로 유지한다.
