# 2026-10-21 — Codex 직접 호출과 로컬 월간 달력

## 범위와 사용자 결정

- [이슈 #2](https://github.com/samuel426/jobshot-mcp/issues/2)의 현재 Codex 대화 입력 도구 직접 호출을 확인했다.
- 사용자가 Windows·Codex 우선으로 [이슈 #3](https://github.com/samuel426/jobshot-mcp/issues/3)의 월간 달력 구현을 진행하도록 선택했다. Claude Code·macOS 확인은 배포 전 과제로 옮긴다.
- `codex/monthly-calendar` 브랜치에서 작업하며 Google 전송·서류·AI 평가는 포함하지 않는다.

## 구현

- 공고 목록과 명시적 등록/해제, dashboard/index.html 재생성 도구를 추가했다.
- 보관·분석만 한 공고는 제외하고 미정·상시 공고는 별도 표시한다. 등록 해제는 이전 상태를 복원하며 재입력은 등록 상태를 보존한다.
- 서버 없이 열 수 있는 HTML에 월 이동·오늘·원문 링크·지난 마감 표시와 한국 시간 기준 자정/재활성화 갱신을 구현했다.
- 개인 자료와 평가 본문을 HTML에 넣지 않고, 스크립트 형태의 공고 문구는 데이터로 표시한다. 링크는 인증 정보 없는 http(s)만 허용한다.
- 기존 저장 잠금과 원자적 파일 교체를 사용한다. 상태 저장 뒤 HTML 쓰기 실패는 dashboard_updated:false와 재생성 안내를 반환한다.

## 검증

- 현재 대화 입력 도구 직접 호출: 가상 긴 공고 신규 저장·중복 재입력, 원본/기록 해시·수정 시각 보존, 분할 픽셀·좌표 일치 확인.
- 파일·stdio 테스트와 jsdom에서 등록/해제, 입력 호환, 손상 데이터/링크/정션/하드 링크 거부, HTML 실패 복구, 날짜 경계와 페이지 이벤트를 검증한다.
- 가상 공고 6개가 담긴 로컬 미리보기를 만들었다. 실제 자료나 설정·미리보기 생성물은 커밋하지 않는다.
- 브라우저 도구의 file:// 정책 차단으로 실제 브라우저 시각 확인은 미완료다. DOM 테스트를 시각 검증으로 대신 기록하지 않는다.
- Windows 전체 테스트 37개·문서 22개/로컬 링크 23개·Git 제외 검사 통과. npm 의존성 감사는 취약점 0건을 반환했다.
- Codex CLI 0.163.0-alpha.11에서 새 도구 6개 발견·등록·HTML 생성·해제 통합 검사 통과. 앱 업데이트로 이전 실행 파일 경로가 사라진 사례를 확인해 검사 명령의 경로 오류 안내도 보완했다.
