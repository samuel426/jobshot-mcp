# 2026-10-19 — 프로젝트 신뢰 등록과 Codex 연결 검사

## 범위

[이슈 #2](https://github.com/samuel426/jobshot-mcp/issues/2)의 연결 검증을 이어서 진행했다.
사용자가 현재 프로젝트의 신뢰 등록을 명시적으로 승인했다.
`codex/codex-connection-check` 브랜치에서 반복 가능한 개발용 검사와 검증 기록을 추가한다.

## 완료한 작업

- 기존 사용자 설정을 백업하고 바이트를 보존한 채 현재 프로젝트 경로 하나만 신뢰 등록했다. 백업·설정·개인 경로는 Git에 넣지 않았다.
- 프로젝트 설정 제외 사유가 해소되고 CLI에서 활성 서버를 조회하는 것을 확인했다.
- 실제 프로젝트 설정으로 시작한 Codex App Server 임시 세션에서 `connected`와 도구 3개를 확인했다. 가상 긴 공고 저장·분할·중복 재입력·원본/기록 보존·일정 미등록을 검증했다.
- `npm run check:codex -- --codex-bin <실행 파일 절대 경로>`를 추가했다. 별도 CODEX_HOME과 가상 자료를 tmp에 생성하며 사용자 설정은 변경하지 않는다.
- 반복 검사에서 가상 개인 자료 조회와 불변, 경로 거부, 분할본 픽셀·좌표, 중복, 마감 미정과 일정 미등록을 확인한다. 모델 턴과 저장되는 새 대화는 만들지 않는다.

## 검증과 남은 범위

- Windows Codex CLI 0.163.0-alpha.10.2에서 실제 프로젝트 연결 검사와 격리된 반복 검사 통과.
- 잘못된 실행 파일(Node)을 지정한 실패 경로 확인: 서버 종료 오류, 종료 코드 1.
- 로컬 `npm run check`: Windows 테스트 27개 통과, 건너뜀 없음. 문서 21개·로컬 링크 23개와 Git 제외 검사 통과. `git diff --check` 통과.
- 현재 대화의 도구 목록에는 아직 JobShot이 없다. App Server 검사 성공을 현재 대화의 직접 호출 성공으로 기록하지 않는다.
- 앱 재연결 후 현재 대화의 호출, Claude Code, macOS 확인은 남아 있다. 달력 단계는 시작하지 않았다.
