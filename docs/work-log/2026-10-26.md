# 2026-10-26 작업 기록

## 요청과 범위

- 사용자 요청으로 기존 PR 병합 후 오늘 작업을 진행했다.
- [PR #15](https://github.com/samuel426/jobshot-mcp/pull/15)의 Windows·Linux CI 성공과 최신 head를 확인하고 merge commit `ee8a120162314557a2ea1f75711763dc07cfb2d3`으로 병합했다. 개별 커밋을 보존했다.
- 병합된 main에서 `codex/google-calendar`를 만들고 [이슈 #5](https://github.com/samuel426/jobshot-mcp/issues/5)의 4단계만 진행했다. 5단계 배포는 시작하지 않았다.
- 사용자는 첫 버전에서 JobShot 전용 캘린더를 선택했다. 기존 캘린더 목록 권한 대신 `calendar.app.created` 하나를 요청한다. 자소서 항상 평가·점수 이유, 이력서 정성 평가·숫자 유보 결정도 유지한다.

## 구현

- Windows Desktop OAuth CLI: PKCE·state·loopback 콜백, 권한 확인·토큰 갱신·연결 해제. 토큰은 프로젝트 밖 LocalAppData에 DPAPI CurrentUser로 보호한다.
- 전용 캘린더 생성·기존 연결 재사용·생성 결과 불명확 시 중복 생성 방지와 표식 기반 복구.
- `calendar_preview`는 네트워크 없이 전송 내용과 공고 해시를 반환한다. `calendar_sync`는 별도 Google 요청을 받은 선택 공고만 종일 마감 일정으로 등록·갱신한다.
- 안정적인 이벤트 ID·소유 표식·etag·If-Match로 중복·외부 수정 충돌을 처리한다. 삭제·참석자·반복 일정은 자동 변경하지 않는다.
- 응답 유실·409·412·할당량 오류·로컬 기록 실패와 수동 파일 변경을 구분한다. 공고·개인 원본·로컬 달력은 유지한다.
- 실제 자료·계정·토큰은 사용하지 않았다. 가상 테스트 파일은 tmp/에만 생성했다. 연결 파일 제외 규칙과 사용 안내를 보완했다.

## 검증과 남은 작업

- TypeScript 빌드와 Windows 전체 테스트 72개가 통과했다(실패·건너뜀 0). 문서 28개·로컬 링크 48개, 비공개 경로 18개·공개 경로 10개 및 Git 제외 규칙 검증도 통과했다. CI 결과는 PR에서 확인한다.
- 격리 Codex App Server에서 도구 11개 발견·기존 작성 흐름·Google 로컬 미리보기를 확인했다. 모델 턴·새 영구 대화·사용자 설정 변경은 실행하지 않았다.
- 현재 대화의 MCP는 기존 8개 도구다. 새 서류·Google 도구의 현재 대화 직접 호출과 사용자 작성 흐름 확인은 남아 있다.
- 실제 OAuth 설정 파일은 제공되지 않았다. 실제 Google 브라우저 동의·전용 캘린더 생성·등록·갱신·권한 철회와 공개 배포용 앱 검증은 미완료다. 자동 테스트 성공을 실제 연결 성공으로 표시하지 않는다.
- Windows 외 인증 정보 보관은 미지원이다. macOS·Claude Code·새 환경·모바일 달력·친구 피드백 검증은 후속 범위다.
