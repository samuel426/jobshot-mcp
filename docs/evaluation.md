# 평가 기준 v0.1

AI가 공개 공고와 사용자가 제공한 근거를 기준으로 수행하는 참고 평가다.
기업 내부 채점이나 실제 합격 확률을 의미하지 않는다. 첫 사용자 검증 후 기준을 조정한다.

## 직무 적합도: 100점

| 항목 | 배점 |
| --- | --- |
| 필수 자격과 요구사항 근거 | 30 |
| 직무 기술·업무 경험의 관련성 | 30 |
| 프로젝트·성과의 구체적 근거 | 25 |
| 우대사항과의 관련성 | 15 |

필수 요건은 점수와 별도로 충족·미충족·미확인으로 표시한다.
나머지 점수가 높다고 필수 자격 미충족을 숨기지 않는다.
공고에 없는 평가 항목은 해당 없음으로 두고 적용 가능한 배점 합계를 기준으로 100점 환산한다.
자료 부족은 미충족과 구분한다. 중요한 항목이 미확인이면 최종 점수를 유보하고 필요한 자료를 알린다.
분석만 요청한 경우 `직무 적합도 NN/100`과 핵심 근거 최대 3개로 마무리한다.

## 자소서: 문항별 100점

| 항목 | 배점 |
| --- | --- |
| 질문에 대한 직접적인 답변 | 25 |
| 직무·기업 요구사항과의 연결 | 25 |
| 경험·행동·성과의 구체성과 근거 | 30 |
| 논리·가독성 | 15 |
| 분량·형식 준수 | 5 |

문항마다 항목별 점수, 합계, 근거 문장, 개선 우선순위를 기록한다.
인사담당자 관점의 전달력과 실무자 관점의 구체성을 구분한다.
실제 평가자 신분이나 특정 기업의 평가표를 가진 것처럼 표현하지 않는다.

자료에 없는 경험·수치는 생성하지 않는다. 확인되지 않은 내용은 확인 필요로 표시한다.
사실 충돌이 있으면 제출 가능한 완성본이라고 부르지 않고 확인을 먼저 요청한다.
글자 수는 공백 포함 여부와 플랫폼 기준을 기록한다. 확인되지 않은 기준을 임의로 확정하지 않는다.

기록에는 평가 기준 버전, 입력 문항·공고·개인 자료 버전, 평가 시각을 남긴다.
모델·입력 차이로 점수가 달라질 수 있으며 점수 상승 자체를 품질 보장으로 삼지 않는다.
기계가 읽을 배점은 [evaluation-rubric.json](evaluation-rubric.json)에 함께 관리한다.

## 서류 저장 시 적용

초안만 요청하면 평가를 붙이지 않는다. 문항별 평가 요청 시 자소서에 위 배점을 적용하며 이력서는 이 기준으로 채점하지 않는다.
미확인 사실·충돌·추가 확인 정보, 미평가 항목 또는 개인 자료에 연결된 경험 근거 부재가 있으면 해당 문항의 총점을 유보한다.
분량 기준 미확인은 형식 점수를 유보하고, 확인한 제한을 벗어난 초안은 형식 점수를 0 또는 유보로 둔다.
글자 수는 로컬 Unicode 코드 포인트 기준의 참고값으로 실제 지원 플랫폼 계산과 다를 수 있다.
본문·문항·분량 기준·자료 버전과 근거는 [지원서류 저장 계약](applications.md)에 따라 새 버전으로 보존한다.
